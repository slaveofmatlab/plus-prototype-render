# Special Orders Process 项目说明

## 一、项目概述

本文件夹用于对**特殊订单格式**进行预处理，将非标准化的商品描述转换为统一的中文商品名称格式，以适配后续的数据预处理和搜索匹配算法。

### 理想输出格式示例

```
金龙鱼牌超精雪花麦芯粉(小麦粉)25kg
金龙鱼精炼一级菜籽油10L
五得利特精小麦粉25kg
干豆角（称重）
大白菜（散称）
```

核心特征：
- 品牌名后带"牌"字（如"金龙鱼牌"）
- 保留商品名、规格、包装信息
- 去除冗余的英文、类目、储存类型、国家等字段
- 繁体字统一转为简体字

## 二、客户预处理方法

### 2.1 香格里拉（XGLL）

#### 脚本功能

`XGLL/process_orders_xgll.py` 将香格里拉报价单中的中英混合商品描述，通过繁转简、去英文、去类目、去储存/国家信息、品牌加"牌"字等规则，提取为标准中文商品名称。

#### 使用方法

**环境依赖：**

```bash
pip install openpyxl opencc-python-reimplemented
```

**运行方式：**

```bash
# 在项目根目录下执行（默认处理 XGLL/ 下的两个报价单）
python XGLL/process_orders_xgll.py

# 处理指定的报价单文件
python XGLL/process_orders_xgll.py XGLL/报价--杭州老香749.xlsx

# 处理多个指定文件
python XGLL/process_orders_xgll.py XGLL/报价--杭州老香749.xlsx XGLL/报价--杭州老香967.xlsx

# 指定输出目录
python XGLL/process_orders_xgll.py XGLL/报价--杭州老香749.xlsx -o output/
```

脚本启动后会先运行内置测试用例验证逻辑正确性，然后处理文件。不指定输入文件时，默认处理 `XGLL/` 目录下的两个报价单（`报价--杭州老香749.xlsx` 和 `报价--杭州老香967.xlsx`），输出文件自动命名为 `<原文件名>_商品名称表.xlsx`，保存在输入文件同目录下。

**输入要求：**

输入文件为 `.xlsx` 格式，第一行为表头，从第二行开始读取数据。商品描述位于第 1 列（A列），对应表头"描述"。其余列（尺寸、数量、单价等）不参与处理。

**输出格式：**

输出文件为 `.xlsx` 格式，包含两列：

| 列 | 表头 | 说明 |
|----|------|------|
| A | 序号 | 从 1 开始递增 |
| B | 客户商品名 | 处理后的标准中文商品名称 |

**使用案例：**

```bash
# 案例1：直接运行，处理默认的两个报价单文件
python XGLL/process_orders_xgll.py

# 案例2：在 Python 中作为模块调用单条处理
python -c "from XGLL.process_orders_xgll import process_description; print(process_description('SNACKS MAGIC CHILI (HUANG FEI HONG) 308GM DR CHN 小食 香脆椒 (黄飞红) 308GM 干货 中国 (小食 香脆椒 (黄飞红) 308GM 干货 中国)'))"
# 输出: 香脆椒 (黄飞红牌) 308GM

# 案例3：在 Python 中批量处理自定义文件
python -c "
from XGLL.process_orders_xgll import process_excel_file
process_excel_file('XGLL/报价--杭州老香749.xlsx', 'XGLL/输出_商品名称表.xlsx')
"
```

#### 预处理流程

脚本对每条商品描述依次执行以下 6 个步骤：

```
原始描述
  │
  ▼
Step 1: 繁体转简体 + 移除尾部重复括号
  │  使用 OpenCC (t2s) 转换繁体字
  │  递归移除末尾的 (...) 重复段（如 "(小食 香脆椒...干货 中国)"）
  │
  ▼
Step 2: 提取中文部分
  │  通过匹配已知类目列表定位中文区域起始位置
  │  避免英文部分中偶然出现的中文字符（如"度"）造成误判
  │
  ▼
Step 3: 移除末尾的储存类型和国家信息
  │  从末尾依次匹配并移除：国家名 → 储存类型 → 国家名
  │  储存类型：干货、冰鲜、急冻、常温
  │
  ▼
Step 4: 移除开头的类目信息
  │  匹配最长类目前缀并移除
  │  保护逻辑：若移除类目后剩余内容以括号开头，
  │           说明类目即商品名本身（如"日本清酒 (菊正宗)"），予以保留
  │           若移除类目后仅剩单汉字，同样保留（如"火腿 方"）
  │
  ▼
Step 5: 移除包装描述和英文残留
  │  移除 PER PKT / PER BTL / PER BAG / PER PC 等
  │  移除 FZ / CH / DR 等储存标记
  │  移除 BTL 前缀、2-3位英文国家代码、独立数字编码等
  │
  ▼
Step 6: 品牌加"牌"字 + 清理
  │  括号内品牌名后添加"牌"字：(黄飞红) → (黄飞红牌)
  │  合并多余空格，输出最终商品名称
```
