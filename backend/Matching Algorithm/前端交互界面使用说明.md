# 商品价格推荐 - 商品匹配查询系统 使用说明

## 快速启动

```bash
cd "Product_Price_Recommendation\Matching Algorithm"
python app.py
```

启动后访问：**http://127.0.0.1:7861**

---

## 一、系统概述

本系统用于将客户订单中的商品名称自动匹配到标准商品库，支持**单条查询**和**批量匹配**两种模式。匹配算法基于 BM25 + 2-gram 二路召回，结合品牌过滤、规格加权、属性词命中等多维度重排，最终输出匹配结果与置信度评分。

## 三、模块一：单条查询

### 3.1 功能说明

输入一条订单商品名称，系统从标准商品库中检索最相似的产品，展示 Top 1 匹配详情及 Top 50 候选列表。

### 3.2 界面布局

```
┌────────────────────────────────────────────────────┐
│  左侧 (查询区)          │  右侧 (候选列表区)          │
│  ┌──────────────────┐  │  ┌──────────────────────┐ │
│  │ 输入商品名称      │  │  │ Top 50 候选列表       │ │
│  │ [文本输入框]      │  │  │ [下拉框]              │ │
│  │                  │  │  │                      │ │
│  │ [查询按钮]        │  │  │ 切换候选时左侧同步更新 │ │
│  │                  │  │  └──────────────────────┘ │
│  │ Top 1 匹配结果    │  │                           │
│  │ - 商品名称        │  │                           │
│  │ - 产品编码        │  │                           │
│  │ - 品牌/规格/属性  │  │                           │
│  │ - 匹配得分        │  │                           │
│  └──────────────────┘  │                           │
────────────────────────────────────────────────────┘
```

### 3.3 操作步骤

1. **输入商品名称**：在文本框中输入订单商品名称（如"五得利五星特精小麦粉 25kg"）
2. **点击查询**（或按回车键）：系统自动执行匹配
3. **查看结果**：
   - 左侧显示 Top 1 匹配详情（名称、编码、品牌、规格、属性、得分）
   - 右侧下拉框展示 Top 50 候选，可点击切换查看不同候选的详情

### 3.4 结果字段说明

| 字段 | 说明 |
|------|------|
| 商品名称 | 标准商品库中的产品名称 |
| 产品编码 | 标准产品的唯一编码 |
| 匹配得分 | 综合召回相似度分数，越高越相似 |

## 四、模块二：批量匹配

### 4.1 功能说明

上传客户询价表单（Excel 文件），系统自动识别商品名称列，批量匹配标准商品库，结果以分页表格展示，支持行内切换候选、置信度筛选、导出等功能。

### 4.2 操作流程

```
上传文件 → 选择工作表 → 确认名称列 → 设置参数 → 开始匹配 → 查看/调整结果 → 导出
```

### 4.3 各功能区详细说明

#### 4.3.1 上传与参数区

| 控件 | 说明 |
|------|------|
| **上传询价表单** | 支持 .xlsx / .xls 格式，上传后自动识别所有子表（Sheet） |
| **工作表（可多选）** | 多选后合并处理，系统自动计算公共列并识别名称列 |
| **商品名称列** | 自动识别（关键词：商品名称、品名、产品名称等），也可手动选择 |
| **备选数量 (Top K)** | 每行保留的候选数量，默认 20，范围 5~50 |

#### 4.3.2 表单预览

点击"表单预览（前10行）"可展开查看上传文件的原始数据，确认名称列识别是否正确。

#### 4.3.3 匹配结果表

结果以分页表格展示，每页 15 行：

| 列 | 说明 |
|------|------|
| **序号 / 客户商品名称** | 行序号 + 原始订单商品名称（多表合并时显示来源子表名） |
| **匹配商品品名** | 下拉框，显示当前选中的匹配结果，点击可展开切换其他候选 |
| **标准产品编码** | 当前选中候选的产品编码 |
| **召回得分** | 名称/规格/品牌的综合召回相似度（4位小数） |
| **置信度** | 独立评估匹配正确概率（0~1），基于品牌(50%)+规格(20%)+核心名(30%)三维度加权 |

**行内切换操作：**
- 点击任意行的下拉框 → 展开该行的 Top K 候选列表
- 选择新的候选 → 该行的编码、召回得分、置信度自动更新
- 未匹配的行显示"未匹配到结果"

#### 4.3.4 置信度筛选工具栏

用于快速定位需要人工核查的低置信度结果：

| 控件 | 说明 |
|------|------|
| **置信度下限** | 筛选结果的最小置信度（默认 0.0） |
| **置信度上限** | 筛选结果的最大置信度（默认 0.6） |
| **筛选区间结果** | 仅显示置信度在 [下限, 上限] 范围内的行 |
| **清除筛选** | 恢复显示全部结果 |

> 提示：下限设为 0 时，未匹配的行也会纳入筛选结果。

#### 4.3.5 分页导航

| 控件 | 说明 |
|------|------|
| **上一页 / 下一页** | 翻页浏览 |
| **页码输入框 + 跳转** | 直接跳转到指定页（输入页码后点击"跳转"） |
| **页码信息** | 显示"第 X / Y 页（共 Z 条）" |

#### 4.3.6 导出功能

点击"导出匹配结果（基于原表）"按钮：
- 基于上传的原始 Excel 文件
- 在商品名称列后插入 3 列：**标准商品名称**、**标准产品编码**、**匹配置信度**
- 新增三列以浅蓝色底色区分
- 支持多工作表，各表写入同一 xlsx 文件的不同 Sheet
- 导出文件自动下载到临时目录

## 五、匹配算法说明

### 5.1 处理流程

```
原始商品名称
    │
    ▼
┌─────────────┐
│ 1. 品牌检测  │  基于品牌词库 + "XX牌"模式识别
└──────┬──────┘
       ▼
─────────────┐
│ 2. 名称标准化│  去除品牌、统一单位(kg→g, L→mL)、清洗文本
└──────┬──────┘
       ▼
┌─────────────┐
│ 3. 分词     │  动态规划全局最优匹配 + 规格词库 + 属性词库
└──────┬──────┘
       ▼
┌─────────────┐
│ 4. 规格提取  │  分离规格信息（支持乘法结构如"2*500g"）
└──────┬──────┘
       ▼
┌─────────────┐
│ 5. 召回     │  BM25 + 2-gram 二路召回，品牌过滤粗筛
└──────┬──────┘
       ▼
┌─────────────┐
│ 6. 重排     │  规格匹配加权 + 属性词命中 + 散称优先加分
└──────┬──────┘
       ▼
┌─────────────┐
│ 7. 置信度   │  品牌(0.5) + 规格(0.2) + 核心名编辑距离(0.3)
└─────────────┘
```

### 5.2 置信度评分规则

| 场景 | 品牌得分 | 规格得分 | 核心名得分 |
|------|---------|---------|-----------|
| 双方均无品牌 | 1.0 | - | - |
| 订单无品牌，结果有品牌 | 0.8 | - | - |
| 订单有品牌，结果无品牌 | 0.1 | - | - |
| 品牌匹配（互相包含） | 1.0 | - | - |
| 品牌不一致 | 0.0 | - | - |
| 规格完全一致 | - | 1.0 | - |
| 规格部分包含 | - | 0.5 | - |
| 纯文本规格（散称等）字符串一致 | - | 1.0 | - |
| 订单无规格，结果为散称 | - | +0.3加分 | - |

## 六、常见问题

### Q1: 上传文件后没有识别到工作表？
检查 Excel 文件是否包含有效数据，系统会自动跳过空白 Sheet。

### Q2: 商品名称列识别错误？
系统按优先级匹配关键词（商品名称 > 品名 > 产品名称），若均不匹配会回退到含"名称"或"name"的列。可在"商品名称列"下拉框中手动选择正确的列。

### Q3: 某些商品显示"未匹配到结果"？
说明标准商品库中无相似产品。可检查商品名称是否包含错别字，或尝试简化名称后重新查询。

### Q4: 置信度很低但看起来匹配正确？
置信度由品牌、规格、核心名三维度综合评估。若订单名称缺少品牌或规格信息，对应维度得分会偏低，属正常现象。

### Q5: 多工作表合并时列不对齐？
系统自动计算所选工作表的公共列。若各表结构差异较大，建议分别处理各 Sheet。

### Q6: 导出文件为空？
确保已完成批量匹配（状态栏显示"批量匹配完成"），且工作表下拉框中已选择至少一个 Sheet。
