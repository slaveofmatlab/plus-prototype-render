# 商品名称标准化工具 (Product Name Normalizer)

独立可迁移的商品名称标准化工具，用于将商品库中的商品名称进行标准化处理，便于后续的 BM25 检索匹配。

## 快速开始

```bash
cd Product_Normalizer
pip install -r requirements.txt
python run_normalizer.py "输入文件.xlsx"
```

## 文件结构

```

│   ├── __init__.py               # 包初始化，导出公共接口

│   ├── normalize.py              # 标准化核心逻辑（6步处理）
│   ├── tokenizer.py              # 分词器（DP最优拆分 + 首字索引加速）

│   ├── utils.py                  # 工具函数
```

## 使用方法

### 方法1: 命令行处理 Excel 文件（推荐）

```bash
cd Product_Normalizer

# 处理Excel文件（输出自动生成）
python run_normalizer.py "输入文件.xlsx"

# 指定输出文件
python run_normalizer.py "输入文件.xlsx" "输出文件.xlsx"
```

> **说明**: 输入文件可以在任意位置。输出默认生成在输入文件同目录，命名为 `原文件名_normalized_时间戳.xlsx`。

### 方法2: Python 模块方式

```bash
cd Product_Normalizer

# 处理Excel文件
python -m normalizer.main -i "products.xlsx"

# 指定输出文件
python -m normalizer.main -i "products.xlsx" -o "output.xlsx"

# 测试单个商品名称
python -m normalizer.main --name "百瑞意大利式整火腿（去骨）6KG*1条" --brand "百瑞"
```

### 方法3: 代码调用

```python
import sys
sys.path.insert(0, 'Product_Normalizer')

from normalizer import normalize_query, process_excel

# 标准化单个商品名称
result = normalize_query("百瑞意大利式整火腿（去骨）6KG*1条", brand="百瑞")
print(result['normalized_name'])  # 意大利式 整火腿 去骨 6000g 1条
print(result['tokens'])           # ['百瑞', '意大利式', '整火腿', '去骨', '6000g', '1条']

# 批量处理Excel文件
df = process_excel("products.xlsx", "output.xlsx")
```

## 输入输出说明

### 输入 Excel 要求

必须包含以下列名之一（自动识别）：

| 可识别列名 | 说明 |
|------|------|
| 商品名称 | 最常见 |
| 标准产品名称 | 已标准化文件 |
| 产品名称 | 备选 |
| 品名 | 备选 |

> **表头自动检测**：如果第一行是数据而非表头，工具会自动尝试第 2–6 行作为表头。

### 输出 Excel

在原文件基础上新增三列：

| 新增列 | 说明 |
|--------|------|
| `normalized_name` | 标准化后的商品名称 |
| `tokens` | JSON 格式的 token 列表 |
| `detected_brand` | 自动检测到的品牌名 |

## 标准化流程

```
原始名称 → 品牌检测(AC自动机) → Step1 文本清洗 → Step2 单位统一 
         → Step3 包装标准化 → Step4 品牌移除 → Step5 括号处理 
         → Step6 术语统一 → DP分词 → 输出
```

| 步骤 | 功能 | 示例 |
|------|------|------|
| 品牌检测 | Aho-Corasick 多模匹配 | `可口可乐330ml` → 检测到"可口可乐" |
| Step1 | 全角→半角、统一符号 | `（去骨）` → `(去骨)` |
| Step2 | 单位统一为 g/mL | `6KG` → `6000g`, `500ml` → `500mL` |
| Step3 | 包装数量标准化 | `20包/箱` → `20包 箱` |
| Step4 | 移除品牌名 | `可口可乐330mL` → `330mL` |
| Step5 | 去括号保留内容 | `(去骨)` → `去骨` |
| Step6 | 称重术语统一 | `称重` → `散称` |
| 分词 | DP最优拆分 + jieba兖底 | `整火腿6000g` → `['整火腿', '6000g']` |

## 常见问题

**Q: 提示找不到词库文件？**  
A: 确保 `Spec_words/` 文件夹与 `normalizer/` 文件夹在同一目录下。

**Q: 输出文件在哪里？**  
A: 默认生成在输入文件同目录，命名为 `原文件名_normalized_时间戳.xlsx`。

**Q: 如何更新词库？**  
A: 直接编辑 `Spec_words/` 下的 Excel 文件，重新运行即可生效。

**Q: 报错 "cannot be used in worksheets"？**  
A: 商品名称中含有不可见控制字符，工具已自动清洗，若仍报错请检查源文件编码。

**Q: 报错 "缺少商品名称列"？**  
A: 工具支持识别「商品名称/标准产品名称/产品名称/品名」四种列名，并自动检测表头行（第2-6行）。若仍失败，请确认文件含有上述列名之一。
