# 报价建议 Demo - 迁移指南

本项目已设计为**完全自包含、可独立迁移**的架构。将整个 `[Demo]-Price_Recommendation` 文件夹复制到任意位置即可运行，无需外部依赖。

## 📁 项目结构

```
[Demo]-Price_Recommendation/
├── backend/                    # FastAPI 后端
│   ├── main.py                 # 应用入口
│   ├── config.py               # 路径配置（自动基于 __file__ 计算）
│   ├── routers/                # API 路由
│   └── services/               # 业务逻辑
├── frontend/                   # React + Vite 前端
│   ├── src/                    # 源代码
│   ├── package.json            # npm 依赖
│   └── vite.config.ts          # Vite 配置（代理 /api → localhost:8000）
├── Matching Algorithm/         # 匹配算法模块
├── Pre-process/                # 商品名称预处理模块
│   ── Product_Normalizer2.0/  # 归一化器
├── Database/                   # 标准产品库
│   ── RSM_723_normalized_*.xlsx
├── 上海德立安-报价数据.xlsx    # 历史报价数据
── 上海德立安-采购数据.xlsx    # 采购价格数据
├── uploads/                    # 上传文件临时存储
└── requirements.txt            # Python 依赖
```

##  快速启动

### 1. 安装后端依赖

```bash
cd "Demo-Price_Recommendation"
pip install -r requirements.txt
```

### 2. 安装前端依赖

```bash
cd frontend
npm install
```

### 3. 启动服务

**终端 1 - 后端：**
```bash
cd backend
python -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

**终端 2 - 前端：**
```bash
cd frontend
npm run dev
```

访问 http://localhost:3000

## 🔧 路径自适应机制

所有路径均基于 `__file__` 自动计算，支持任意目录迁移：

| 配置文件 | 关键代码 | 说明 |
|---------|---------|------|
| `backend/config.py` | `PROJECT_ROOT = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))` | 项目根目录 |
| `Matching Algorithm/service.py` | `_DB_DIR = os.path.join(os.path.dirname(os.path.abspath(__file__)), '..', 'Database')` | 数据库目录 |
| `Pre-process/.../config.py` | `os.path.join(os.path.dirname(os.path.abspath(__file__)), '..', 'Spec_words', ...)` | 词库路径 |

## ✅ 自包含性检查清单

- [x] **无绝对路径**：所有文件路径通过 `os.path.join()` + `__file__` 动态计算
- [x] **无外部依赖**：匹配算法、预处理模块、数据库均在项目内
- [x] **数据文件内置**：报价数据、采购数据、产品库均随项目复制
- [x] **前端代理配置**：Vite 开发服务器代理 `/api` 到本地后端
- [x] **依赖声明完整**：`requirements.txt` 和 `package.json` 包含所有必需依赖

## ️ 注意事项

1. **端口占用**：默认后端 8000、前端 3000，如被占用需修改配置
2. **Python 版本**：推荐 Python 3.9+
3. **Node.js 版本**：推荐 Node 16+
4. **uploads 目录**：首次启动会自动创建，用于存储上传的 Excel 文件

## 🐛 常见问题

**Q: 启动后提示找不到模块？**  
A: 确保在正确的目录下执行命令，或使用绝对路径。

**Q: 前端无法连接后端？**  
A: 检查后端是否在 8000 端口运行，查看浏览器控制台是否有 CORS 错误。

**Q: 匹配结果为空？**  
A: 检查 `Database/` 目录下是否有 `RSM_723_normalized_*.xlsx` 文件。
